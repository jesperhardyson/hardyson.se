# Hardyson.net

## Lokal utveckling med Ddev
* Skapa config i grav root-katalog med `ddev config`
* Starta miljön med `ddev start`
* Stoppa med `ddev stop`
###Läs mer här om vad som behövs för att köra ddev: [Grav docs]([test](https://learn.getgrav.org/17/webservers-hosting/local-development-with-ddev))
